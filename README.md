# TelePro — Professional Messenger & Network

A professional messaging and networking platform combining:
- **Telegram-identical instant messaging**: Channels, direct chats with unique `@handles`, folders, unread badges, and rich media/chat bubbles.
- **LinkedIn professional profiles & resumes**: Headlines, work experience timeline, education, skills with endorsement counters, and connect requests.
- **Google Meet virtual rooms**: Live camera preview, microphone controls, screen share simulation, participant rosters, reactions, and in-call chat.
- **Industry Organizations Directory**: Search and filter organizations across categories (Tech, Startups, AI & ML, Design, Finance, Product) and join group chats.
- **Firebase Real-Time Cloud**: Real-time Firestore sync and Google Authentication.

---

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

## GitHub Actions Deployment Setup

This repository contains an automated GitHub Actions workflow (`.github/workflows/deploy.yml`) configured to automatically build, lint, and deploy on pushes to `main` or `master`.

### Setting up Firebase Hosting Secrets in GitHub:
1. Go to your GitHub repository -> **Settings** -> **Secrets and variables** -> **Actions**.
2. Add one of the following deployment secrets:
   - **`FIREBASE_SERVICE_ACCOUNT_SINCERE_PLATEAU_Z5WLS`**: A service account JSON key generated from Google Cloud / Firebase console (`Project Settings` > `Service accounts` > `Generate new private key`).
   - OR **`FIREBASE_TOKEN`**: A CI token generated by running `npx firebase-tools login:ci`.
3. Push to `main` or run the workflow manually via the **Actions** tab.
